# Elf Intern
This was created for my friend's discord server. It was more of an experiment to see how things work, and I do not claim that everything is perfectly secure or even viable in anything other than small servers with trusted friends. Right now, the bot supports the following commands using the '$' as the prefix:
taskhelp -> help message
tease -> outputs a lewd message. Currently working on increasing the messages by employing users to add to the database
suggest [@user] [\"message\"] -> add to a user's suggestion database
mySug -> outputs your list of suggestions
remSug [Suggestion #] -> removes a suggestion based on index (when viewing list, numberings are accurate)
memePiece [hot/new/top] -> grabs a meme from the memePiece subreddit
rap -> outputs a message with a link to the priate rap from One Piece

Hope this works for now. I'll be updating this further as I decide to do more with it.
